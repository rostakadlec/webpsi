# webpsi
Web o psech – druhy, zajímavosti, obrázky

Cerna, zelena

· Nadpis: Psi

· Krátké představení – co jsou psi a proč jsou oblíbení

· Základní informace – délka života, váha, potrava

· Plemena psů – například buldog, rotvajler, zlatý retrívr

· Zajímavosti o psech – pár krátkých zajímavých faktů

· Obrázky psů

· Navigace nahoře – odkazy, které po kliknutí přesunou na jednotlivé části stránky
